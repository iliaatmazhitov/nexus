# Nexus
Nexus - корпоративный мессенджер

## Требования
Необходимо установить для работы проекта:
- `go`: 1.26.8
- `make`
- `gcc` для работы `-race`
- Docker compose (используется для `make up` и `make down`)
- `make up` и `make down` имеют проверку на наличие compose файла и пока выдают что файла нет, compose.yaml
добавляется отдельной задачей

## Линтер
Линтер устанавливается самостоятельно благодаря `make tools`
- установка происходит в директорию: `backend/bin/`
- версия линтера задана в `Makefile` в `GOLANGCI_LINT_VERSION`

## Правила запуска
Для запуска проверки команда `make check`
- для ознакомления с возможностями использовать `make help`
- проверка содержит в себе `vet -> lint -> go test -race`
- также перед `make check` необходимо запустить `make fmt` без этого `make check` упадёт в случае ошибок оформления кода
